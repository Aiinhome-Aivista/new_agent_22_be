# Project Guidelines and Rules

Before writing, modifying, or reviewing any code, you MUST always consult and follow the latest documentation and coding standards located in the `knowledge_base/` directory of this project.

- **Standards:** Check `knowledge_base/standards/` for naming conventions, YAML configurations, and testing rules.
- **Patterns:** Check `knowledge_base/sample_scripts/` for implementation patterns (e.g., error topic patterns, stateful or single topic patterns).

Always ensure your code strictly adheres to these dynamically updated rules. Do not rely on assumptions; if a rule or pattern is defined in the `knowledge_base` folder, it must be followed exactly.
